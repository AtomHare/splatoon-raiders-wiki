# Builds

Loadouts (weapon + ink tank + gadgets) recommended by the community, and **why
they work**. Each build is one page in this folder.

Stats for each piece of gear are on [Inkipedia](https://splatoonwiki.org); a
build page explains the reasoning, the playstyle and the matchups.

## How to add a build

Copy `templates/strategy.md` into `docs/builds/`, rename it (for example
`aggressive-frontline.md`) and fill it in. It appears in the menu automatically.

Or [submit a build with the form](https://github.com/AtomHare/splatoon-raiders-wiki/issues/new?template=1-strategy.yml).
