# Splatoon Raiders Community Wiki

Strategies, builds, videos and player tips for **Splatoon Raiders**, gathered
from across the community (mostly X/Twitter and YouTube) into one place.

This wiki is about **Splatoon Raiders Strategies**. For raw game data (weapon stats,
enemies, items, story), use [Inkipedia](https://splatoonwiki.org), the
reference Splatoon wiki. We link to it instead of copying it.

## Contribute

Found a great tip, video or strategy? You don't need to know Git.

- **Submit a form:** [open a new issue](https://github.com/AtomHare/splatoon-raiders-wiki/issues/new/choose)
  and pick Build, Strategy, Video or Community tip.
- **Edit a page:** click the :material-file-edit-outline: edit button at the
  top of any page. GitHub opens its web editor and turns your change into a
  pull request.

Read the [contribution guide](https://github.com/AtomHare/splatoon-raiders-wiki/blob/main/CONTRIBUTING.md)
first. Rule number one: **check Inkipedia first**. Game data goes there, not here.

Browse every page by topic on the [tags page](tags.md).
